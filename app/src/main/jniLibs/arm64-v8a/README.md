Native binaries are generated by `scripts/build_core.py`, not committed here.
Gradle packages `app/build/generated/native-core/jniLibs/arm64-v8a/librtp2httpd.so`.
It is an Android NDK-built PIE executable launched from nativeLibraryDir, not a JNI library.
Run `./scripts/build-release.sh` to fetch the locked source, build and package it.
OpenWrt `.apk` packages and desktop Linux executables are not Android application packages.
