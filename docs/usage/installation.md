# 安装与使用

## 选择安装包

要求 Android 8.0/API 26 或以上。ARM32 指 armeabi-v7a（ARMv7/NEON），ARM64 指 arm64-v8a。64 位 CPU 如果运行 32 位 Android，应使用 ARM32 或通用包。

| 包 | 用途 |
| --- | --- |
| 通用包 | 同时包含 ARM32 和 ARM64，不确定系统架构时优先选择 |
| ARM32 包 | 只包含 armeabi-v7a 核心 |
| ARM64 包 | 只包含 arm64-v8a 核心 |

选择 `-signed.apk` 安装。`-unsigned.apk` 是未签名构建产物，需要先[签名](../development/building.md)。三种包使用相同应用 ID，覆盖升级需要同一签名；卸载或清除数据会删除私有配置，操作前可在管理页导出 YAML。

## 安装和首次配置

1. 通过 U 盘、下载目录或文件管理器安装已签名 APK，按电视系统要求允许该来源安装。
2. 在电视应用列表打开 rtp2httpd，点击“启动”。首次没有配置时，会启用 `0.0.0.0:5141` 管理监听，等待选择上游。
3. 手机与盒子连接同一局域网，浏览器打开 App 显示的管理地址，例如 `http://192.168.1.100:5141`。
4. 选择实际接收 IPTV 上游流的网卡，按需要设置代理监听网卡和端口，保存并应用。
5. 服务状态正常后，通过代理地址及具体流路径使用转发服务。实际网卡名、组播源和播放路径由盒子网络及 IPTV 上游决定，不能直接照抄别的设备配置。

管理端口默认 5141，代理端口默认 5140。代理根路径 `/` 返回 404 不一定表示启动失败；可以访问代理端口的 `/status` 检查状态。状态接口返回 200 只能说明核心响应，不能证明真实 IPTV 流已正常转发。

## 电视首页和网页

管理地址和代理地址显示在左上角，运行状态与启动、重启、停止按钮居中。监听所有地址时显示当前网络 IP；监听 `127.0.0.1` 时直接显示该地址，不附加说明文字。`0.0.0.0` 是监听设置，手机浏览器应使用盒子的实际局域网 IP。

- 启动：启用转发，缺少上游配置时等待配置。
- 重启：按已保存参数重新启动核心。
- 停止：关闭转发，网页管理入口保留。

状态点绿色表示核心正常运行，灰色表示未启用、等待配置或启动中，红色表示故障。网页按手机单列适配，最大宽度 1024px，大屏居中。保存、启停等操作直接执行，不弹确认框或成功提示；出错时显示原因。

管理页面无需账号或令牌，能够访问管理监听地址的设备可以修改配置和控制服务。详细字段、绑定限制与 API 见[配置说明](configuration.md)。

## 开机恢复与配置保存

已配置应用会在开机完成后恢复前台服务并读取私有 YAML；已停止的转发保持停止。网络未就绪时会重试。首次安装尚未启动配置的应用不自动启用；系统“强行停止”会影响自动恢复，应重新打开应用并启动。

配置保存在应用私有文件目录，不需要 Root 或外部存储权限。覆盖安装保留配置，卸载与清除数据会删除配置。系统回收恢复与开机恢复已实现，但不同机顶盒固件的后台策略仍需实际验证，不能保证进程永远不被结束。

## ADB 是可选方式

安装和日常使用不要求 ADB。有调试环境时可以执行：

```sh
adb install -r app-release-signed.apk
adb shell am start -n local.rtp2httpd/.MainActivity
```

修改启动参数、管理绑定或排查后台服务时使用[配置说明中的 ADB 命令](configuration.md)。ADB 路径、连接方式和文件名应替换为自己的环境。

## 常见问题

| 问题 | 检查方式 |
| --- | --- |
| 手机打不开管理页 | 看管理地址是否为 127.0.0.1；确认使用盒子实际 IP、手机同一局域网且未启用访客隔离 |
| 停止后还可以打开网页 | 停止按钮只关闭转发，管理服务仍保留 |
| 绿色状态却不能播放 | 检查上游网卡、IPTV 流地址、组播接收和网络路由；状态不等于流量验证 |
| 升级提示签名不一致 | 需要使用原签名构建的包；不要为覆盖升级重新生成随机密钥 |
| 重启后状态异常 | 查看网页错误与最近日志，检查网卡/IP 是否已就绪；设备验收清单见开发计划 |
| 想修改管理地址或端口 | 当前网页不应用 management 段；通过 ADB 停止整个服务后修改 |

[继续阅读配置与管理接口](configuration.md)

电视首页的“管理地址”和“代理地址”后各有独立状态灯：绿色表示管理监听已建立或代理核心运行，红色表示管理监听失败或代理报错/重试，灰色表示未启用、未运行或等待启动。停止代理时管理灯可以保持绿色。
